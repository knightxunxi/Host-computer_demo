# 项目路线图

## 1. 总体路线

项目按“先文档、再骨架、再模拟、再业务功能、最后部署”的顺序推进。每一阶段都保留可验证产物，避免只写代码而缺少需求、设计和测试依据。

## 2. 里程碑

| 阶段 | 名称 | 目标 | 主要产物 |
| --- | --- | --- | --- |
| M0 | 仓库与需求 | 建立 Git 仓库和需求文档体系 | README、需求分析、流程文档、路线图、产线模型与用例 |
| M1 | 总体设计与工程骨架 | 将需求转为架构设计，并创建 Qt Widgets + CMake 最小可运行程序 | 总体设计文档、CMake 工程、主窗口、基础目录结构 |
| M2 | 模拟器 | 实现虚拟包装线/PLC 状态机 | 模拟器模块、模拟点位、状态切换 |
| M3 | 协议模拟 | 通过模拟链路学习 TCP Socket、Modbus TCP、串口、Modbus RTU、OPC UA 和 Snap7/S7 | 协议实验记录、模拟连接说明 |
| M4 | 通信层 | 建立上位机与模拟器的数据交换 | 通信接口、轮询机制、断线重连 |
| M5 | 监控与控制 | 完成主界面状态展示和基础控制 | 设备总览、工位状态、启停复位 |
| M6 | 数据与报警 | 实现 SQLite 记录、报警和操作日志 | 数据库、报警历史、日志查询 |
| M7 | 配方与报表 | 实现配方管理、趋势曲线和数据导出 | 配方界面、曲线、CSV/Excel 导出 |
| M8 | 测试与部署 | 完成测试、打包和部署说明 | 测试报告、安装包、部署文档 |
| M9 | 用户与权限 | 建立可切换用户、角色权限和真实操作审计 | 用户表、默认用户、切换用户对话框、权限校验 |
| M10 | 批次管理 | 将生产过程按批次组织，便于追溯和报表统计 | 批次表、批次开始/结束、批次产量统计 |
| M11 | 配方增强 | 支持多配方、版本、复制和下发记录 | 配方列表、版本字段、配方操作审计 |
| M12 | 报警增强 | 增加报警筛选、等级、处理建议和确认流程 | 报警筛选、报警详情、处理说明 |
| M13 | 模拟器增强 | 让模拟器覆盖更多产线异常和节拍变化 | 速度扰动、质量波动、传感器状态模拟 |
| M14 | 模拟器拆分 | 将模拟器拆为独立进程，通过协议对接上位机 | 独立模拟器程序、协议联调说明 |
| M15 | 通信健壮性 | 完善超时、重连、质量标识和通信诊断 | 通信状态页、错误统计、重连策略 |
| M16 | 测试增强 | 扩展单元测试、集成烟测和回归测试 | GoogleTest、协议测试、数据库测试 |
| M17 | 部署增强 | 补齐版本号、配置迁移、日志目录和安装包 | 发布包、安装脚本、部署检查清单 |
| M18 | 协议扩展 | 在 Modbus TCP 基础上扩展 RTU、Snap7 或 OPC UA | 协议适配层、协议实验文档 |

## 3. 学习重点

| 主题 | 对应能力 |
| --- | --- |
| Qt Widgets | 工业界面布局、表格、对话框、状态栏、菜单和工具栏 |
| CMake | 现代 C++ 工程组织、依赖管理和构建配置 |
| 模拟器 | 状态机、虚拟设备、无硬件联调 |
| 协议模拟 | 无真实设备时通过本机服务端、虚拟串口和协议模拟器学习通信 |
| 通信 | TCP、串口、Modbus、OPC UA、Snap7/S7、断线重连、超时处理 |
| 多线程 | UI 线程与通信线程分离、异步任务和线程安全 |
| 数据库 | SQLite 表设计、增删改查、历史查询和数据导出 |
| 报警 | 报警触发、确认、恢复、等级和追溯 |
| 权限 | 用户角色、权限控制和操作审计 |
| 部署 | Windows 打包、运行库收集、配置管理和版本发布 |

## 4. 后续模块拆分建议

| 模块 | 职责 |
| --- | --- |
| UI 模块 | 主窗口、设备总览、报警页、配方页、报表页 |
| 通信模块 | 连接管理、协议适配、点位读写、断线重连 |
| 模拟器模块 | 虚拟产线状态、虚拟 PLC 点位、报警注入 |
| 业务模块 | 生产流程、控制命令、批次管理、状态转换 |
| 数据模块 | SQLite 访问、数据模型、历史查询、导出 |
| 权限模块 | 登录、角色、权限判断、操作审计 |
| 公共模块 | 日志、配置、错误处理、工具函数 |

## 5. 当前阶段完成定义

- M0-M12 已形成第一版可运行上位机：包含内置模拟器、Modbus TCP 通信、主监控、报警筛选与详情、多配方、趋势曲线、CSV 导出、用户权限、批次管理、烟测和打包脚本。
- 下一阶段从 M13 开始，先增强模拟器传感器/执行机构和故障注入，再逐步进入模拟器拆分和通信健壮性。

## 6. M9-M18 后续路线

| 顺序 | 阶段 | 学习重点 | 验收方式 |
| --- | --- | --- | --- |
| 1 | M9 用户与权限 | 用户表、默认账号、中文显示名、快速切换用户、角色权限、真实操作日志 | 登录/切换后状态栏显示用户，操作日志能看到真实用户和角色 |
| 2 | M10 批次管理 | 批次号、计划数量、开始/结束时间、批次产量和良率 | 启动批次后生产数据按批次归档 |
| 3 | M11 配方增强 | 多配方列表、配方版本、复制、导入导出、下发记录 | 能选择不同配方并查看历史下发记录 |
| 4 | M12 报警增强 | 报警查询、等级筛选、处理建议、确认和恢复闭环 | 报警页可按条件筛选并追踪处理过程 |
| 5 | M13 模拟器增强 | 传感器/执行机构细化、速度波动、随机不良、故障注入 | 不靠真实设备也能覆盖常见联调场景 |
| 6 | M14 模拟器拆分 | 模拟器独立运行、协议边界、联调部署 | 上位机只通过协议连接独立模拟器 |
| 7 | M15 通信健壮性 | 超时、断线重连、通信质量、诊断信息 | 拔掉/重启模拟器后上位机能恢复连接 |
| 8 | M16 测试增强 | 单元测试、数据库测试、协议回归测试 | 一条命令完成主要回归验证 |
| 9 | M17 部署增强 | 配置文件、日志、版本、安装包和升级说明 | 交付包能在目标 Windows 环境独立运行 |
| 10 | M18 协议扩展 | Modbus RTU、Snap7/S7、OPC UA 任选其一扩展 | 新协议通过同一通信接口接入业务层 |
