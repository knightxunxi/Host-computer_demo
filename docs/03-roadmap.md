# 项目路线图

## 1. 总体路线

项目按“先文档、再骨架、再模拟、再业务功能、最后部署”的顺序推进。每一阶段都保留可验证产物，避免只写代码而缺少需求、设计和测试依据。

## 2. 里程碑

| 阶段 | 名称 | 目标 | 主要产物 |
| --- | --- | --- | --- |
| M0 | 仓库与需求 | 建立 Git 仓库和需求文档体系 | README、需求分析、流程文档、路线图、产线模型与用例 |
| M1 | 总体设计与工程骨架 | 将需求转为架构设计，并创建 Qt Widgets + CMake 最小可运行程序 | 总体设计文档、CMake 工程、主窗口、基础目录结构 |
| M2 | 模拟器 | 实现虚拟包装线/PLC 状态机 | 模拟器模块、模拟点位、状态切换 |
| M3 | 协议模拟 | 通过模拟链路学习 TCP Socket、Modbus TCP、串口、Modbus RTU、OPC UA 和 Snap7/S7 | 协议实验记录、模拟连接说明 |
| M4 | 通信层 | 建立上位机与模拟器的数据交换 | 通信接口、轮询机制、断线重连 |
| M5 | 监控与控制 | 完成主界面状态展示和基础控制 | 设备总览、工位状态、启停复位 |
| M6 | 数据与报警 | 实现 SQLite 记录、报警和操作日志 | 数据库、报警历史、日志查询 |
| M7 | 配方与报表 | 实现配方管理、趋势曲线和数据导出 | 配方界面、曲线、CSV/Excel 导出 |
| M8 | 测试与部署 | 完成测试、打包和部署说明 | 测试报告、安装包、部署文档 |

## 3. 学习重点

| 主题 | 对应能力 |
| --- | --- |
| Qt Widgets | 工业界面布局、表格、对话框、状态栏、菜单和工具栏 |
| CMake | 现代 C++ 工程组织、依赖管理和构建配置 |
| 模拟器 | 状态机、虚拟设备、无硬件联调 |
| 协议模拟 | 无真实设备时通过本机服务端、虚拟串口和协议模拟器学习通信 |
| 通信 | TCP、串口、Modbus、OPC UA、Snap7/S7、断线重连、超时处理 |
| 多线程 | UI 线程与通信线程分离、异步任务和线程安全 |
| 数据库 | SQLite 表设计、增删改查、历史查询和数据导出 |
| 报警 | 报警触发、确认、恢复、等级和追溯 |
| 权限 | 用户角色、权限控制和操作审计 |
| 部署 | Windows 打包、运行库收集、配置管理和版本发布 |

## 4. 后续模块拆分建议

| 模块 | 职责 |
| --- | --- |
| UI 模块 | 主窗口、设备总览、报警页、配方页、报表页 |
| 通信模块 | 连接管理、协议适配、点位读写、断线重连 |
| 模拟器模块 | 虚拟产线状态、虚拟 PLC 点位、报警注入 |
| 业务模块 | 生产流程、控制命令、批次管理、状态转换 |
| 数据模块 | SQLite 访问、数据模型、历史查询、导出 |
| 权限模块 | 登录、角色、权限判断、操作审计 |
| 公共模块 | 日志、配置、错误处理、工具函数 |
