## 2. 场景定义

本项目采用“全自动小型瓶装包装产线”作为学习场景。这里的全自动不是无人产线，而是指正常生产流程由 PLC/模拟器自动控制，上位机负责监控、参数、报警、记录和人机操作。

现场人员假设：

| 场景 | 人员配置 |
| --- | --- |
| 正常稳定生产 | 1 个操作员看 1 条线 |
| 自动化程度较高 | 1 个操作员可看 2-3 条类似产线 |
| 换型、调试、维护 | 1 个操作员 + 1 个工程师 |
| 系统管理 | 管理员负责账号、权限和系统配置 |

产线流程定义：

```text
空瓶上料 -> 输送定位 -> 灌装 -> 旋盖 -> 检测 -> 贴标/喷码 -> 分拣剔除 -> 下料/装箱
```

与塑料造粒这类连续过程产线相比，包装线更偏离散动作控制。它重点关注产品到位、动作完成、检测结果、产量计数和不合格品剔除；连续过程产线更关注温度、压力、转速、电流和过程曲线稳定性。

## 3. 工位模型

| 编号 | 工位 | 作用 |
| --- | --- | --- |
| ST-01 | 上料/理瓶 | 空瓶进入产线，并以可控节奏进入输送线 |
| ST-02 | 输送/定位 | 输送产品，并在关键工位挡停和定位 |
| ST-03 | 灌装 | 按配方设定量完成液体灌装 |
| ST-04 | 旋盖 | 自动供盖、压盖或旋盖 |
| ST-05 | 检测 | 判断液位、重量、瓶盖等质量结果 |
| ST-06 | 贴标/喷码 | 贴标签或打印批号、日期 |
| ST-07 | 分拣剔除 | 将不合格品推出主输送线 |
| ST-08 | 下料/装箱 | 合格品输出到收集或装箱位置 |

公共系统不归属于单个工位，但必须常驻监控：

```text
急停、安全门、气压、主电源、通信状态、自动/手动模式、总运行状态
```

## 5. 虚拟 PLC 点位表初版

第一版采用 Modbus TCP 点位模型。后续可以通过相同语义映射到真实 PLC、OPC UA 节点或 Snap7/S7 DB 块。

| 数据区 | 类型 | 方向 | 用途 |
| --- | --- | --- | --- |
| Coils | 位 | 上位机读写 | 启动、停止、复位、报警确认等命令 |
| Discrete Inputs | 位 | 上位机只读 | 传感器、安全状态、现场输入 |
| Holding Registers | 16 位寄存器 | 上位机读写 | 配方、参数、控制设定 |
| Input Registers | 16 位寄存器 | 上位机只读 | 状态码、产量、过程数据 |

| 参数/配方 | 管理产品参数并下发到 PLC/模拟器 | 工程师、管理员 |

## 7. 典型用例

### 7.1 启动产线

前置条件：

```text
通信正常、急停正常、安全门关闭、气压正常、无未恢复报警、自动模式、已选择配方、批次已开始
```

流程：

```text
操作员点击启动
上位机检查权限和基础条件
上位机写 CMD_START = 1
PLC/模拟器进入运行状态
上位机读取 IR_SYSTEM_STATE = 2
界面显示运行中
记录操作日志
```

失败处理：通信断开、急停触发、安全门打开、气压不足、有报警、未选择配方或非自动模式时，不下发启动命令，并提示明确原因。

### 7.2 停止产线

停止按钮按正常停止处理，不等同于硬件急停。

流程：

```text
操作员点击停止
上位机写 CMD_STOP = 1
PLC/模拟器停止自动流程
设备进入停止或待机
上位机刷新状态
记录操作日志
```

真实设备急停应由硬件急停按钮和安全回路完成，上位机只负责显示急停状态和记录报警。

### 7.3 设备复位

复位用于故障条件解除后让系统回到可启动状态，不清空生产数据，也不等同于报警确认。

流程：

```text
操作员点击复位
上位机写 CMD_RESET = 1
PLC/模拟器进入复位中
执行机构回原位
可恢复报警被清除
系统进入待机
记录操作日志
```

急停未释放、安全门未关闭、气压不足或执行机构未回原位时，复位失败并保持报警提示。

### 7.4 报警确认

报警确认表示用户已经看到并确认报警，不代表强制消除报警。

报警生命周期：

| 状态 | 含义 |
| --- | --- |
| ActiveUnacked | 报警正在发生，未确认 |
| ActiveAcked | 报警正在发生，已确认 |
| ClearedUnacked | 报警条件已恢复，未确认 |
| Closed | 报警已恢复且已确认 |

流程：

```text
操作员点击报警确认
上位机写 CMD_ALARM_ACK = 1
PLC/模拟器标记报警已确认
数据库记录确认人和确认时间
若报警条件已恢复，报警关闭
若报警条件仍存在，报警保持但显示已确认
记录操作日志
```

### 7.5 开始批次

流程：

```text
用户选择配方
输入或生成批次号
设置目标产量
上位机写入配方参数
上位机写 CMD_BATCH_START = 1
数据库创建批次记录
界面显示当前批次
```

推荐主流程：

```text
选择配方 -> 开始批次 -> 切换自动模式 -> 启动产线
```

### 7.6 结束批次

流程：

```text
用户点击结束批次
系统确认当前产量、良品、不良品
上位机写 CMD_BATCH_END = 1
数据库保存结束时间和汇总数据
界面清除当前批次或进入待机
记录操作日志
```

系统运行中不建议允许结束批次。结束批次不清空历史记录。

### 7.7 切换用户

目标：现场换班或临时维护时快速切换当前操作用户，并保留操作追溯。

流程：

```text
用户点击当前用户或切换用户
系统显示最近登录用户和全部启用用户
用户选择目标账号
输入密码或 PIN
认证成功后切换当前用户
界面按新角色刷新权限
记录退出旧用户和登录新用户日志
```

失败处理：密码错误、账号禁用、权限不足或数据库不可用时，不切换当前用户，并提示原因。

## 8. 用户与中文显示名规则

系统保存用户列表用于登录和快速切换，但不保存明文密码。密码应保存为哈希值。

用户字段建议：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| user_id | 1001 | 内部唯一 ID |
| login_name | op001 | 登录账号，建议字母、数字、下划线 |
| display_name | 张三 | 中文显示名，用于界面和日志识别 |
| role | 操作员 | 操作员、工程师、管理员 |
| enabled | true | 是否启用 |
| password_hash | - | 密码哈希，不保存明文 |
| last_login_at | 2026-05-30 21:30:00 | 最近登录时间 |

规则：

```text
登录账号用于稳定登录和数据关联
显示名称允许中文，方便现场识别
操作日志同时记录 user_id、login_name、display_name 和 role
快速切换可以记住用户列表，但必须重新输入密码或 PIN
```

示例日志：

```text
2026-05-30 21:30:12 张三(op001, 操作员) 点击启动 成功
```
