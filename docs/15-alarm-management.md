# M12 报警增强说明

## 1. 本阶段目标

M12 的目标是让报警页从“最近记录列表”升级为更接近现场使用的报警处理界面。

当前实现范围：

- 按状态筛选报警。
- 按等级筛选报警。
- 按工位筛选报警。
- 按报警码、报警名称、工位关键词查询。
- 报警表显示确认时间、恢复时间和关闭时间。
- 选中报警后显示详情。
- 根据报警码显示处理建议。
- 最近操作日志仍与报警页放在一起，便于追溯。

## 2. 报警状态

| 状态 | 含义 | 页面显示 |
| --- | --- | --- |
| `ActiveUnacked` | 报警正在发生，未确认 | 进行中未确认 |
| `ActiveAcked` | 报警正在发生，已确认 | 进行中已确认 |
| `ClearedUnacked` | 报警条件已恢复，未确认 | 已恢复待确认 |
| `Closed` | 报警已恢复且已确认 | 已关闭 |

报警关闭需要满足两个条件：报警条件恢复，并且有人确认。

## 3. 页面说明

“报警记录”页面包含四块：

1. 筛选栏：状态、等级、工位、关键词。
2. 最近报警表：显示生命周期字段。
3. 报警详情：显示当前选中报警的状态、确认信息、时间和处理建议。
4. 最近操作：显示控制、配方、批次、报警相关操作日志。

## 4. 处理建议

当前处理建议以内置规则实现，例如：

| 报警码 | 报警 | 建议方向 |
| --- | --- | --- |
| `5001` | 缺盖 | 检查理盖机、落盖轨道、瓶盖余量和缺盖传感器 |
| `7001` | 缺标签 | 检查标签卷、标签传感器和放卷机构 |
| `1003` | 气压不足 | 检查气源压力、调压阀和气管漏气 |
| `4001` | 料液不足 | 检查料液桶液位、供料泵和灌装压力 |

真实项目中处理建议通常来自报警配置表，后续可以将这些规则迁移到数据库或配置文件。

## 5. 手工验证

运行程序：

```powershell
.\build\upkun-hmi.exe
```

验证步骤：

1. 打开“模拟器”页面。
2. 点击“触发缺盖”。
3. 打开“报警记录”页面。
4. 将等级筛选为“警告”，应能看到缺盖报警。
5. 将工位筛选为“旋盖”，应能看到缺盖报警。
6. 在关键词中输入 `5001` 或 `缺盖`，点击“刷新记录”，应能筛出该报警。
7. 选中报警行，详情区应显示处理建议。
8. 在“主监控”点击“报警确认”，确认人应显示当前用户。
9. 回到“模拟器”清除故障或在主监控点击“复位”，刷新后状态应进入恢复或关闭状态。

## 6. 当前限制

- 时间范围筛选尚未实现。
- 处理建议仍写在代码中，后续应配置化。
- 只支持当前报警确认，暂不支持历史报警批量确认。
- 还没有报警导出报表。
