# M21 报表中心说明

## 1. 阶段目标

M21 基于已有 SQLite 数据实现报表中心，不新增数据库表，重点学习如何从生产数据、报警数据和趋势数据生成统计结果。

## 2. 报表内容

报表中心包含：

- 批次数量、总产量、良品、不良和良率。
- 报警总数、未闭环报警数。
- 趋势样本数量、平均速度和平均重量。
- 批次明细。
- 按工位和等级统计的报警次数。
- 按日期统计的趋势样本和平均过程量。

## 3. 导出

导出路径：

```text
data/report-export.csv
```

导出内容包含汇总、批次报表、报警统计和趋势日汇总。

## 4. 后续扩展

后续可以继续扩展日报、周报、Excel 导出、图表打印和按时间范围查询。
