# M20 工位详情与手动调试说明

## 1. 阶段目标

M20 将主监控中的整体状态展开到工位级视图，便于理解包装线每个工位的传感器、执行机构和运行状态。

## 2. 新增页面

“工位详情”页面包含：

- 上料、输送定位、灌装、旋盖、检测、贴标/喷码、分拣剔除、下料。
- 每个工位显示传感器状态、执行机构状态和当前运行状态。
- 报警工位会在状态列显示报警停机。

## 3. 手动调试

页面提供：

- 切到自动。
- 切到手动。
- 剔除测试。

这些调试命令通过统一命令入口发送，并要求工程师及以上权限。

## 4. 学习价值

这个页面用于建立“上位机画面不是随便摆控件，而是围绕工位、信号、执行机构和状态机组织”的意识。
