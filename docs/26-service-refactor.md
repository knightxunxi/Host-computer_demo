# M23 服务层整理说明

## 1. 阶段目标

M23 先做低风险服务层整理：不大规模重构 UI，而是把控制命令从页面直连设备客户端，调整为主窗口统一入口，再调用服务层检查。

## 2. 改动点

- 主监控页和工位详情页的控制命令统一进入 `MainWindow::handleLineCommandRequested`。
- 启动命令先经过 `LineControlService::canStart` 检查。
- 工程师调试命令要求工程师及以上权限。
- 拒绝启动、权限不足和设备未初始化都会记录操作日志。

## 3. 回归测试

新增回归测试覆盖：

- 正常快照允许启动。
- 存在报警时拒绝启动。
- 拒绝原因返回“当前存在报警”。

## 4. 后续重构方向

后续可以把 `MainWindow` 中的批次、配方、报表和连接管理继续拆到应用服务层。
